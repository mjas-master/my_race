# 01. 요구사항 정의서 — my_race

## 1. 목표와 성공 기준
| 항목 | 목표 |
|---|---|
| 핵심 가치 | 이번 주 경주에 대해 "누가 유력한가, 왜 그런가"를 1분 안에 파악 |
| 정량 목표 (출시 3개월) | 주말 DAU 1,500 / 유료 전환율 3% / 30일 리텐션 25% |
| 예측 품질 게이트 | 앱 출시 전 과거 12개월 백테스트에서 **복승(1~2위 내 포함) 적중률 ≥ 45%**, 1착 적중률 ≥ 25%. 미달 시 출시 보류 |

## 2. 사용자 페르소나
- **주말 경마팬(주 타깃)**: 금~일 경마장/장외에서 관람, 예상지 구매 경험 있음. 빠른 판단 도움을 원함.
- **데이터형 분석가**: 스스로 지표를 비교하고 싶어함. 차트·원자료 접근 원함(프리미엄 타깃).

## 3. 범위
### 3.1 MVP (이번 개발 범위)
1. 성인 인증(19세 이상 자기확인 + 앱스토어 연령등급) 및 면책 고지
2. 이번 주 경주 목록 (서울/부경/제주, 날짜·경마장 필터)
3. 경주 상세: 출마표 + 추천 순위(1~3위 강조) + 근거 지표 4~6개
4. 경주마 상세: 최근 10전 성적, 주로·거리별 성적, 기수 궁합
5. 기수 상세: 최근 성적, 승률/연대율 추이
6. 조교사 상세 (P1)
7. 경주 결과 + 우리 예측 적중 이력(경마장별·주간·누적)
8. 설정: 알림, 구독 관리, 문의, 약관/개인정보, 데이터 출처 표기
9. 프리미엄 잠금: 근거 상세·기수 궁합·적중 이력 상세는 구독자만
10. AdMob 배너(무료 사용자, 성인 콘텐츠 라벨)

### 3.2 후속 (Out of MVP)
모의 배팅, 커뮤니티, ML 모델 v2(GBM), 위젯, 웹 버전, 실시간 배당 갱신

## 4. 데이터 원천
- 공공데이터포털 한국마사회 OpenAPI (서비스키 필요)
  - 출전표(출마표) 조회 — 경주 편성·마번·부담중량·기수·조교사
  - 경주 결과(순위/기록/배당) 조회
  - 경주마 상세·기수·조교사 정보 조회
  - 경주 계획(연간·주간) 조회
- 갱신 주기: 출마표는 경주 2~3일 전 확정, 결과는 경주 종료 후 수 분~수 시간 내 반영
- 원본 필드명은 `external/KraDto.kt` 에 그대로 두고, 도메인 변환은 `IngestService` 에서만 수행

## 5. 법적·정책 제약 (필수)
| 구분 | 요구 |
|---|---|
| 표현 | "마사회 공인/제휴/공식/추천"류 문구 금지. 허용: "한국마사회 공공데이터 기반", "출처: 공공데이터포털" |
| 성격 | 배팅 대행·승식 판매·사설 링크 일체 금지. 앱은 정보 제공만 |
| 연령 | 19+ 자기확인 게이트, 스토어 연령등급 성인 |
| 면책 | 첫 실행·경주 상세 하단에 "예측은 참고 정보이며 결과를 보장하지 않습니다" 상시 표기 |
| 광고 | AdMob 정책상 도박 관련 카테고리 라벨링, 한국 계정 정책 준수. 광고 거절 시 즉시 제거 가능한 플래그 유지(원격 설정) |
| 개인정보 | 회원가입 없이 기기 식별자(익명) + 선택적 이메일. 구독은 스토어 영수증만 보관 |

## 6. 비기능 요구
- 앱 첫 화면 로드 ≤ 1.5초(캐시), API p95 ≤ 300ms
- 경주 당일 트래픽 10배 스파이크 대응 → 읽기 API 응답 캐시(60초)
- 예측 결과는 재현 가능해야 함(입력 스냅샷 + 엔진 버전 저장)
- 오프라인: 마지막 조회 데이터 열람 가능

## 7. 수익 모델
| 플랜 | 가격(안) | 포함 |
|---|---|---|
| 무료 | 0 | 출마표, 결과, 1위 예측만, 배너 광고 |
| 프리미엄 월간 | ₩9,900 | 전체 순위·근거·궤적 차트·적중 이력·경주 전 알림, 광고 제거 |
| 프리미엄 연간 | ₩79,000 | 동일 |
